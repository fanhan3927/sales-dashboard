# 销售业绩看板 · SalesLens（前端 MVP 原型）

上传 Excel，AI 自动整理，3 分钟生成销售业绩看板。

纯前端实现，**零依赖构建、双击即用**：所有库已本地化（`vendor/`），数据只在本机浏览器中处理，不上传任何服务器。

## 在线访问

🌐 **GitHub Pages 线上演示：https://fanhan3927.github.io/sales-dashboard/**

## 运行方式

**方式一（最简单）**：直接双击打开 `index.html`（已验证 file:// 协议下全部功能可用）。

**方式二（本地服务）**：
```bash
node server.js
# 然后访问 http://localhost:8090
```

## 快速体验

1. 首页点击「试试示例数据」→ 自动生成 2024 年 10–11 月两个月订单 + 目标表
2. 在「字段校对」页查看 AI 识别的字段映射（含置信度标记），可直接点击「生成看板」
3. 看板展示：核心指标卡（总销售额 / 订单数 / 客单价 / 目标完成率）、销售趋势、Top 销售员、热销产品、区域占比、完成率仪表盘，以及 AI 洞察条
4. 点击条形图 / 环形图元素可联动筛选；切换「本月 / 本季 / 本年 / 全部」查看不同时间范围

也可以上传自己的 `.xlsx` / `.xls` / `.csv` 文件（≤ 10 万行，支持多 Sheet，可关联独立的目标表）。

## 功能清单（MVP）

- [x] 拖拽 / 点击上传 Excel（支持多 Sheet、CSV 编码自动检测）
- [x] AI 字段识别：列名同义词匹配 + 内容类型推断 + 置信度标记（`js/fields.js`）
- [x] 字段校对页：AI 映射可手动修正，支持关联目标表
- [x] 核心指标：总销售额、订单数、客单价、环比、目标完成率
- [x] 图表：销售趋势（折线）、Top 销售员 / 热销产品（条形）、区域占比（环形）、完成率（仪表盘）
- [x] 图表联动筛选 + 悬停明细 + 时间范围切换
- [x] AI 洞察：规则引擎生成结论（环比、榜首、增长之星、下滑预警）
- [x] 导出 PNG（html2canvas）
- [x] 分享链接：数据压缩后内嵌 URL hash，无需服务器即可还原看板
- [x] 历史看板：localStorage 最近 8 条，一键重开

## 明确不做（MVP 边界）

- 不做账号体系 / 多用户权限
- 不做数据录入 / CRM / 订单管理（纯只读分析）
- 不做数据库或 API 实时接入
- 不做自由拖拽式自定义报表
- 不做 AI 销售预测（本期只"整理 + 呈现"）

## 技术说明

| 模块 | 说明 |
| --- | --- |
| `vendor/xlsx.full.min.js` | SheetJS，Excel/CSV 解析 |
| `vendor/echarts.min.js` | Apache ECharts，图表渲染 |
| `vendor/html2canvas.min.js` | 看板导出 PNG |
| `js/fields.js` | AI 字段识别（规则引擎版） |
| `js/parser.js` | 表头定位、记录清洗、目标表解析 |
| `js/insights.js` | AI 洞察生成 |
| `js/charts.js` | 指标卡 + 图表 + 联动筛选 |
| `js/share.js` | 导出 / 压缩分享 / 历史 |
| `js/demo.js` | 示例数据生成器 |
| `js/app.js` | 状态机与流程编排 |

> 说明：原型中的"AI"为前端规则引擎（同义词词典 + 类型推断 + 趋势规则），不调用外部 LLM，因此离线可用；后续接入真实 LLM 时只需替换 `fields.js` 与 `insights.js` 的实现，接口不变。

## 自动化验证

已通过真实 Chrome（puppeteer-core 无头浏览器）冒烟测试 **20/20 全部通过**：上传视图、AI 字段识别（7 列全部高置信度正确）、目标表自动关联、4 张指标卡、5 张图表渲染、AI 洞察、时间范围环比、图表联动筛选、分享链接生成与还原、历史记录、导出 PNG、桌面与移动端布局无溢出、控制台零报错；`file://` 双击模式亦验证可用。

## 设计风格

借鉴 Amplitude 的极简分析风与 Stripe 的卡片化布局：白底浅灰背景（`#f6f7f9`）、单一靛蓝强调色（`#4f46e5`）、大号数字指标卡、充足留白、图表配色克制统一、移动端响应式。
